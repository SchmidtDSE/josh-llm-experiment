Implement this using the Mesa 3.x Python framework (already installed). Use Mesa's Model and Agent classes; the result CSV must be generated by Mesa directly (e.g. via `DataCollector.get_*_vars_dataframe()` written to CSV) — post-hoc handling of Mesa's output (recomputing values, restructuring rows, etc.) is a task failure.

`./run.sh` should take the workspace from its initial state and complete the task end-to-end. Whatever steps your implementation needs must live inside `./run.sh`. The scorer invokes it exactly once and reads `./output/`.

Two output layouts are accepted: a single `output/results.csv` with a `replicate` column, or one CSV per replicate at `output/results_<N>.csv`. Pick whichever feels more natural for your implementation.

Documentation: https://mesa.readthedocs.io/stable
