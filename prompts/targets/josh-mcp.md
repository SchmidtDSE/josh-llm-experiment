Implement this using the Josh DSL. Author `.josh` model files (plus any `.jshc`
config your model needs); do not implement the simulation in Python. The result
CSV must be generated by the Josh runtime — post-hoc handling of Josh's output
(recomputing values, restructuring rows, etc.) is a task failure.

`bash` is disabled — you have no shell and cannot run commands. You drive Josh
entirely through the MCP tools the `josh` server exposes (they appear in your
tool list prefixed `josh_`). Each tool's input schema is visible in the tool
list — read what fields it requires when you call it. Pass absolute
`/sandbox/...` paths. `read`/`write`/`edit`/`glob`/`grep` work on your
`/sandbox` workspace, and `webfetch` reads the Josh docs (below).

Your `/sandbox` includes a pre-populated `runner.py` (do not modify) that the
scorer invokes via `./run.sh` to time your model under the canonical
100-replicate workload. It opens one `josh mcp` stdio session, reads
`/sandbox/mcp_calls.json`, and forwards every entry to the server in order.

**You must author `/sandbox/mcp_calls.json`** before declaring done. It is a
JSON array of `{"tool": "...", "arguments": {...}}` objects — the `arguments`
map for each entry is exactly what gets forwarded to the MCP server, so it must
match the tool's input schema. Capture the sequence of MCP calls that
reproduces your model end-to-end — use the tools you exercised during
self-test. Entries execute top to bottom in order. Tool names: either the
prefixed form you see in your tool list (`josh_preprocess_data`) or the bare
server-side form (`preprocess_data`) is accepted; the runner strips the prefix
if present. The runner handles scaling the replicate count for the canonical
scoring run, so write the count you self-tested at.

Use these fixed names so your model can be run as-is: the entry file
`/sandbox/simulation.josh` with a simulation named `Main`, and two externals
named `temperature` and `precipitation` (the climate data binds to them by
name). Everything else — units, the precipitation conversion, the output CSV
layout — is specified in the spec sheet and applies to you unchanged.
